# 🏂 スノーボード動画評価アプリ

スノーボードの滑走動画をアップロードして、AI が姿勢やバランス、滑りの質を分析・評価するWebアプリケーションです。

## 特徴

- **動画アップロード**: MP4、MOV、AVIなどの動画形式に対応
- **AI姿勢分析**: MediaPipeを使用した高精度な姿勢推定
- **多角的評価**: バランス、姿勢、滑らかさ、エッジコントロールを総合的に評価
- **視覚的フィードバック**: 動画上に骨格を表示して姿勢を可視化
- **改善アドバイス**: スコアに基づいた具体的な改善ポイントを提示

## 評価項目

### 1. バランス (30%)
- 重心の位置と安定性
- 体重配分の適切性
- 足の真上に体の中心があるかを評価

### 2. 姿勢 (25%)
- 膝の曲げ具合（理想: 120-150度）
- 上体と下半身のアライメント
- 体幹の安定性

### 3. 滑らかさ (25%)
- 動きの流れの一貫性
- ぎこちなさの有無
- ターンのリズム

### 4. エッジコントロール (20%)
- 足首と膝の連動性
- エッジの使い方
- ボードコントロールの精度

## 技術スタック

- **フロントエンド**: React 18 + TypeScript
- **ビルドツール**: Vite
- **AI/ML**: MediaPipe Pose (姿勢推定)
- **スタイリング**: CSS3

## 使い方

1. **動画をアップロード**: 「動画を選択」ボタンをクリックして、スノーボードの滑走動画を選択
2. **動画を確認**: アップロードした動画をプレビューで確認
3. **分析を開始**: 「分析を開始」ボタンをクリック
4. **結果を確認**: 分析完了後、総合スコアと各項目の詳細評価を確認
5. **改善点を確認**: AIが提供する具体的なアドバイスを確認

## 評価システムの仕組み

### MediaPipe Pose による姿勢推定

MediaPipeのPoseモデルを使用して、動画内の人物の33個の身体ランドマーク（関節位置）を検出します。

### スコアリングアルゴリズム

1. **バランススコア**: 体の重心と足の位置関係から計算
2. **姿勢スコア**: 膝の角度と上体のアライメントから評価
3. **滑らかさスコア**: フレーム間の動きの変動を分析
4. **エッジコントロールスコア**: 足首と膝の位置関係から判定

### グレーディング

- **S**: 90-100点 - プロフェッショナルレベル
- **A**: 80-89点 - 上級者レベル
- **B**: 70-79点 - 中級者レベル
- **C**: 60-69点 - 初級者レベル
- **D**: 50-59点 - 練習が必要
- **E**: 0-49点 - 基礎から見直し

## 注意事項

- 最良の分析結果を得るには、全身がフレームに収まっている動画を使用してください
- 動画の解像度が高いほど、より正確な分析が可能です
- 分析には動画の長さに応じて時間がかかる場合があります
- ブラウザで実行されるため、プライバシーが保護されます（動画はサーバーに送信されません）
